# backlog

This directory holds the work items of this repository, managed with
[`nokori`](https://github.com/sile/nokori). An open item is in `open/` and a
closed one is in `closed/`; the directory an item is in is its state, and the
file itself has no status field.

Run `nokori explain overview` to read what a backlog is and what `nokori` does
not do.
