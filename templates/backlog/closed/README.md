# closed

This directory holds the items of this repository that are no longer open:
bugs that were fixed or found not to be bugs, proposals that were accepted or
turned down, and plans that ran or were decided against.

An item is moved here by `nokori close`, and its outcome is in its `##
Outcome` section. A file here is not edited again: what changes after an item
is closed is said by a new item that cites this one.

## Read more

    nokori explain flow

says what closing an item means, and why the file is left as it was written.
